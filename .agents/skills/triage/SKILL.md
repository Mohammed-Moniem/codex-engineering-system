# Triage

1. Preserve the original report and identify the claimed outcome or symptom.
2. Verify what can be checked from code, history, tests, logs, linked artifacts, or a minimal reproduction.
3. Classify: `READY`, `NEEDS-INFO`, `DUPLICATE`, `WONTFIX`, `DEFERRED`, or `INVALID`.
4. If a bounded human decision is missing, use `grill`; if external knowledge is missing, use `questionnaire`.
5. For `READY`, produce an agent-ready brief with scope, evidence, reproduction or desired behavior, acceptance criteria, affected surfaces, risks, and verification.
6. For another disposition, give the evidence and the precise condition that would change it.

Do not inflate a raw request into a speculative solution. A ticket produced by this system already contains the required delivery context and should proceed directly to build when unblocked.
